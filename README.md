# Payout Math

<!-- STUB. Real README before the public flip. Add **Live:** line only once deployed. -->

Incentive programs pay against rules, and almost nobody re-derives the payouts from
those rules. Payout Math re-derives one program year of an invented HVAC manufacturer's
contractor SPIFF and distributor volume-rebate payouts from the program's published
rulebook, and reports what was paid but never earned, then what was earned but never paid.
